## 2026-10-02 선수판 v2 재작성 중 발견·수정
## [10-02] 17세 선수가 U15 팀에 있음
- 증상: 중학교 시작 선수가 17세가 돼도 구단 이름이 "U15".
- 원인: 구단 유스 이름을 입단 때 한 번만 정해서 이후 나이를 반영하지 않음.
- 해결: `L.youthTeamName(short, age)` — 13~15세 U15, 16~18세 U18. 입단 시 및 해마다 nextYear 에서 다시 계산. (engine.js)

## [10-02] 연봉·이적 불일치 (85억 스타가 18억 K리그 제의, 전북 10억→뮌헨 70억→수원 20억)
- 원인: 연봉을 이전 연봉 ×배수로만 계산하고, 리그별 시장 수준·구단 전력과 무관하게 제의를 만듦.
- 해결: 연봉을 `salaryOf(ovr, age, league)`(리그 계수·연령 계수·K리그 상한)로 계산, 제의는 선수 수준(능력치+평판+인기)에 맞는 구단만 생성, 해외는 프리미어리그뿐(수준 ±). 계약 제안은 시장가에서 크게 벗어나지 못하게 제한. 다른 수준 리그로 옮길 땐 이전 연봉을 기준으로 삼지 않음. (engine.js)

## [10-02] EPL에서 K리그로 돌아오면 연봉이 100억대
- 원인: 이적 연봉이 `max(시장가, 현재연봉×0.85)` — 현재 연봉이 EPL 기준이라 K리그 제의에도 적용.
- 해결: 같은 계열 리그(해외↔해외, 국내↔국내)일 때만 현재 연봉을 참조, K1 상한 22억, K2 8억.

## [10-02] 승강 뒤 소속 리그 표시가 어긋나 시즌 시작에서 크래시
- 증상: `Cannot read properties of undefined (reading 'pts')` (playSegment).
- 원인: 이적·상무 복귀로 복원된 S.club.lg 가 승강 이전 값이라, 실제 소속 리그 명단(S.league)과 달라 내 팀이 순위표에 없음.
- 해결: `L.syncClubLeague(S)` 로 승강·상무 전역·이적 후 소속 리그를 명단에 맞춰 보정. 150~200커리어 자동 점검에서 크래시 0건 확인. (engine.js)

## [10-02] 월드컵 우승이 너무 쉬움 (OVR 84에 우승, 전체 2%)
- 원인: 통과 확률이 높고 선수 능력치가 팀 확률을 크게 올림.
- 해결: 월드컵 사다리를 한국 현실 수준(우승 ≈0.3~0.5%)으로 낮추고 개인 영향 계수 `sens` .004로 제한. 401회 출전 중 우승 2회(0.5%). 올림픽 금도 낮춤. (nat.js)

## [10-02] 발롱도르 후보가 너무 흔함 / 영구결번이 43%
- 원인: K리그 선수도 리그 보정 없이 후보 점수 계산, 영구결번 기준(7시즌, 34점)이 낮음.
- 해결: 리그 보정(EPL 0, K1 −6, K2 −10), 경쟁자 점수 상향. 영구결번은 10시즌 + 55점 이상, 약 3%. (awards.js)

## [10-02] 오프시즌 화면이 비어 보임 (저장 후 새로고침 / 유소년)

- 해결: `buildOff()` 로 렌더 때 자동 복원, 유소년은 `off={}`. (ui.js)

## [10-02] (참고 사이트) 군 복무 중 몸값/연봉 혼동
- 오프사이드 화면의 "김천 상무 · 92억 7천만"은 몸값(이적 가치)이지 연봉이 아니었음. 우리 게임은 둘을 분리: 연봉은 상무 연 0.3억 고정, 몸값은 별도 곡선으로 표시하고 안내 문구를 넣음. (engine.js marketValue, ui.js valueChart)

## [10-02] 특성 '천재'를 고르면 능력치가 해마다 떨어짐 (OVR 28 → 10)
- 증상: 천재 특성(나이 곡선 이동 1.5)을 고른 유소년이 매년 성장 대신 −3~4씩 하락.
- 원인: `ageRate(나이+이동값)` 에서 소수 나이로 표를 찾으면 정의되지 않아 기본값 −4 가 반환됨.
- 해결: 표 조회 전에 `Math.round`. (engine.js ageRate) — 10커리어 브라우저 점검에서 발견.
- 교훈: 새 특성/보정값을 넣으면 표 조회·정수 가정이 있는 곳을 확인하고, 특성별 6시즌 성장 테스트(dbg.cjs)를 돌릴 것.

## [10-02] 현역 군 복무 중에 훈련 화면이 그대로 나옴

## [10-02] 김천 상무 복무 중 연봉이 21억 (참고 사이트와 같은 문제)
- 증상: 상무 복무 2년차 오프시즌에 재계약 화면이 떠서 21억 계약을 수락할 수 있었고, 전역 후에도 연봉이 0.3억으로 남을 수 있었음.
- 원인: 계약 화면/수락이 복무 상태를 고려하지 않음. 입대 때 원래 연봉을 덮어써 버림.
- 해결: 복무 중에는 계약 카드 대신 '복무 중' 안내, `acceptContract` 가 복무 중이면 무시, 입대 때 원래 연봉(`milOrigSalary`)을 저장했다가 전역 때 복원. 노드 점검(MILSAL)과 브라우저 10커리어에서 확인. (engine.js, ui.js)
