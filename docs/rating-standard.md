# 능력치 기준 (필수 지침)

이 문서가 이 프로젝트의 능력치 기준이에요. 선수를 추가하거나 숫자를 고칠 때는 항상 이 기준을 따라요.

## 1. 척도와 기준점 (앵커)
- 능력치는 **최종 1~99 정수**를 그대로 써요. 화면에 보이는 값 = 계산에 쓰는 값이에요.
- 기준점은 `js/data_ratings.js`에 적어 둬요. 공식 계산보다 항상 우선해요.

| 선수 | 기준 |
|---|---|
| 호날두 | 전성기 **99**, 2026 현재 **85** |
| 벤제마 | 전성기 **97**, 2026 현재 **87** |
| 손흥민 | 전성기 **95** (토트넘 득점왕 시절) |
| 박지성 | 전성기 **93** (맨유 시절), 2002 월드컵 **90** |
| 안정환 | 2002 월드컵 **90** |
| 이운재 | 2002 월드컵 **91** (골키퍼 중 1위) |

- 골키퍼는 위 기준 때문에 이운재 2002(91) 외에는 89를 넘기지 않아요.
- **능력치를 부풀려서 난이도를 맞추지 않아요.** 난이도는 시뮬레이션의 상대 보정값(`OPP_BONUS`, 현재 쉬움 0 / 어려움 8)으로 맞춰요. 측정(드림팀 4-3-3): 어려움 트레블 약 10%.

## 2. 전성기 / 시즌 / 현재
- **전성기(프라임)** = 그 선수의 커리어 최고 시즌 능력치.
- **시즌 능력치** = 그 해의 능력치. 나이 곡선 + 그 시즌 평가 + 컨디션으로 계산하고, 전성기를 넘지 않아요.
- **2026 현재** = 올해 기록과 폼. **지금이 전성기인 선수만 현재 = 전성기**이고, 나머지는 현재 ≤ 전성기예요.
- 상대 난이도: 쉬움은 상대의 2026 현재, 어려움은 상대의 전성기.

## 3. 리그 간 보정 (K리그2를 일괄로 낮추지 않아요)
- 능력치는 **소속 리그 이름이 아니라 "리그 대비 기록"** 으로 정해요.
  - 실제 기록이 있을 때: `능력치 = 같은 포지션 선수들 중 상대 순위(퍼센타일) × 리그 강도 보정`
  - 리그 강도 보정은 K리그1 = 1.00, K리그2 = 소폭 낮게(0.9대)만 적용해요. 그래서 **K리그2에서 크게 활약한 선수는 K리그1 중위권 선수보다 높을 수 있어요.**
- 리그별 능력치 범위(`CONFIG.LEAGUE_BAND`, [하위권 주전, 상위권 스타]): EPL 62~97, 라리가 60~95, 분데스 58~93, 세리에A 58~93, 리그1 56~90, 사우디 55~90, J1 55~86, K1 55~84, K2 54~80. **같은 5골이라도 EPL 공격수가 K리그 공격수보다 높은 범위에서 환산돼요.**
- 기록이 없는 선수의 추정값도 리그별 평균만 조금 다르고, 한 팀 안에서 넓게 퍼지게 해요(K리그2 선수라고 모두 낮게 잡지 않아요).
- 팀 전력은 그 팀 선수들의 능력치에서 계산하고, 리그 이름으로 따로 깎지 않아요.

## 4. 실측과 추정을 구분
- 공식 기록(출전, 득점 등)으로 계산한 값과 **추정값**(`est: true`)을 구분해서 저장하고, 화면에 "추정"으로 표시해요.
- K리그 API 연동 후에는 추정값을 실제 기록 기반 값으로 교체해요.

## 5. 변경 절차
1. 기준점이 바뀌면 `js/data_ratings.js`를 먼저 고쳐요.
2. 나머지 선수 값은 기준에 맞춰 조정하고, 난이도는 `tools`의 밸런스 측정으로 확인해요.
3. 목표: 어려움 트레블 5~10%, 쉬움에서 평범한 드래프트가 우승 경쟁은 하되 압도하지 않게.
