# 동명이인 판별 결과

선수는 kleague.com 고유번호(id)로 구분합니다. 레전드·대표팀 선수와 이름이 같은 현역 선수가 있을 때:
- **같은 사람(합침)**: 생년이 같거나, 그 레전드가 뛴 구단·시즌이 현역 선수의 K리그 기록에 있을 때 → 같은 id 를 써서 한 사람으로 취급(팀에 둘 다 뽑을 수 없음, 사진 공유)
- **다른 사람(분리)**: 그 외 → 이름만 같은 다른 사람

판별 코드: js/core.js 의 "동명이인" 블록. 틀린 것이 있으면 알려 주세요.
