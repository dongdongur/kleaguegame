# 38-0.app 플레이 조사 노트 (2026-10-02)

비공식 팬 드래프트 게임 https://38-0.app (잉글랜드 1부 역대 선수 11명 뽑기 → 38경기 시뮬). 모바일 폭(375x812)으로 직접 플레이한 기록이다. 내용은 모두 자기 말로 정리했으며 코드·문구·디자인을 가져오지 않는다 (지침 6번).

조사 범위: 본 게임 3판(4-3-3 일반 / 3-5-2 하드 포지션퍼스트 / 4-4-2 쉬움 포지션퍼스트) + 데일리 챌린지 1판 + 유럽 대회 모드 일부 + 리더보드 화면. 계정·로그인·결제·공유·광고 클릭은 하지 않았다. 광고(영상·배너)와 앱 설치 배너가 떠 있었다.

## 한눈에 보기

- 핵심 루프: 룰렛으로 "클럽 + 시즌"이 걸림 → 그 스쿼드에서 1명 선택 → 빈 포지션에 배치 → 11번 반복 → 시즌 시뮬 → 결과/공유.
- 한 판 길이: 드래프트 11회(스핀 약 2~4초 + 선택) + 시뮬 약 1분 + 결과. 짧은 한 판이라 "한 번 더"가 쉽다.
- 목표가 단순하다. "38전 무패(38-0)". 리더보드 상위가 거의 전부 38-0, 동점은 득실차로 가른다. 선수 구성 팀 종합 90 안팎이면 가능한 수준.
- 설정이 매우 많다 (포메이션 12종, 난이도 3, 레이팅 숨김, 드래프트 방식 2, 시즌/전성기 레이팅, 시대 필터, 감독, 유럽, 1월 이적). 처음엔 기본값 그대로 눌러 시작만 해도 된다.
- 판마다 다른 이야기를 자동 생성한다 (득점왕, 도움왕, 골든글러브, 시즌 MVP, 최다 연승, 최다 점수차 경기, 시즌 서사 문단, 팀 성향 라벨).
- 반복 동기: 데일리 챌린지(요일마다 다른 주제), 리더보드(검증 표시), 친구 대결/멀티, 트로피 도전과제, 유럽 모드, 다른 모드(원클럽 XI, 팀메이트 체인, 토너먼트). 수익은 후원(광고 제거·지난 데일리 열람) + 광고.

## 화면 흐름

1. 홈: 큰 "Play" 버튼 하나 + "How it works". 아래에 오늘의 데일리, 마지막 생존자(멀티), 기타 모드 카드. 언어 토글(영/스).
2. 세팅(/game?new=true): 포메이션 12종(선택 시 설명 한 줄과 포지션 미리보기), 난이도(쉬움 리롤 3 / 보통 리롤 1 / 어려움 리롤 0+레이팅 숨김), 레이팅 표시 on/off, 드래프트 방식(스쿼드 먼저 / 포지션 먼저), 레이팅 기준(그 시즌 / 커리어 전성기), 시대 범위, 고급(감독, 유럽 진출, 1월 이적). "Start Draft" 하나로 시작. 설정은 다음 판에도 기억됨(내가 안 바꿔도 이전 숨김 설정이 유지돼 헷갈렸음).
3. 드래프트: 상단에 포메이션·진행률·피치(포지션 빈 점선 원). 피치 아래에 팀 종합/공격/중원/수비/GK 막대. 그 아래에 "Spin the Wheel"(화면 아무 곳 탭이나 스페이스도 가능). 스핀 후 클럽명+시즌이 나오고 그 스쿼드 전원이 레이팅 순 리스트로 나옴(정렬: 레이팅/포지션/성 A-Z). 선수를 누르면 그 자리에서 아래로 "어느 포지션에 넣을까"가 펼쳐지고 한 번 더 누르면 확정. 리롤 버튼은 스핀 결과 옆(남은 횟수 표기).
   - 포지션 먼저 방식: 먼저 빈 슬롯을 고르고 → 스핀 → 그 포지션을 소화하는 선수만 보여줌("n명 해당").
   - 어려움: 레이팅이 물음표로 가려지고, 리스트가 무작위 순서, 선택 시 "Draft ○○ →" 한 번 더 확인.
   - 이미 뽑은 선수 "위치 이동" 버튼으로 슬롯 비우기 가능.
4. 결과 준비: 11명 라인업과 선수별 클럽·시즌·레이팅 목록, 선택적으로 "감독 뽑기"(룰렛, 성향 소개 문구) 또는 감독 없음. 이어서 "사전 예상" 화면: 예상 순위, 예상 승점, 우승/4강/6위/10위/강등 확률, 그 아래 "이 종합 점수면 이 정도"라는 안내.
5. 시즌 진행: 한 라운드씩 타자기처럼 결과 줄이 쌓임(상대·홈원정·스코어·득점자 분 표기). 승/무/패 누적과 득실 표시. 19라운드에서 "1월 이적" 선택 화면으로 멈춤(진행 도중 "Skip to January" 건너뛰기 버튼 존재).
6. 1월 이적: "시장에 들어갈지 / 그대로 갈지". 시장은 슬롯머신처럼 이벤트 이름이 돌다가 하나 걸림. 확인한 것: 클럽 습격(3개 클럽 중 하나를 골라 그 클럽 선수를 랜덤 영입), 바겐 세일(약한 자리에 블라인드 영입). 이름만 본 것: 놓친 물고기, 입찰, 파이어 세일, 거래의 달인. 영입은 가장 약한 포지션이 대상이고 결과(OUT/IN, 몇 점 상승)를 카드로 보여줌. 되돌리기 없음.
7. 결과 화면(스크롤 길이 약 5,300px): 우승/순위 배너와 "예상 순위 vs 실제 순위" 비교 및 한 단어 평가(예: 각본대로 / 말아먹음), 팀 성향 라벨(공·중·수·GK 등급), 시즌 서사 4~5문단, 선수별 골/도움/클린시트/레이팅 표, 승무패·득실, 시즌 어워드(득점왕·도움왕·골든글러브·올해의 선수·감독), 최종 순위표, 리더보드 등록(검증됨 표시), 공유 버튼, "새 판" 버튼. 비로그인 시 "이 기록은 이 기기에만 저장됨, 로그인하면 영구" 유도.
8. 유럽 모드(상위 7위 안이면 진출): 전체 화면 오버레이로 "유럽이 부른다" → 조 추첨(8경기 상대 8팀) → 리그 페이즈 8경기(속도 1x 토글, 끝까지 건너뛰기) → 36팀 순위표(내 순위 표기, 상위 8은 16강 직행) → 토너먼트 대진표(가로 스크롤) → 홈앤어웨이. 최종 목적지에 가상의 결승 무대 이름.
9. 데일리: 매일 주제가 다름(생일, 경기 소식, 이적 뉴스 등). 오늘 건 "특정 선수 고정 + 같은 클럽 선수 2명 + 같은 국적 1명 이상" 같은 필수 조건과 보너스 조건. 시도 5회, "완성 확률" 퍼센트가 선택할 때마다 실시간으로 내려감. 어제 최고 점수 표시. 지난 데일리 111개는 후원자만 열람.

## 좋았던 점

- 한 판이 짧고 입력이 거의 "스핀 → 선수 탭 → 위치 탭"뿐이라 한 손 조작이 쉽다. 화면 아무 곳 탭이나 스페이스로 스핀이 가능.
- 사전 예상(순위·우승 확률)과 사후 비교 구조가 긴장과 이야기를 둘 다 준다.
- 결과 서사가 상황별 템플릿으로 자동 생성되어 매 판 읽을 맛이 있다. 득점왕 활약, 1월 영입 효과, 떠난 선수 성적("나가기 전 6골"), 감독 코멘트까지 연결.
- 점수 외 보상 층이 많다: 시즌 어워드, 트로피/도전과제(예: 서로 다른 국적 11명), 팀 성향 라벨, 최대 점수차 경기.
- 1월 이적은 "되돌리기 없는 도박" 한 번이라 선택이 가볍고 이야기 소재가 된다. 슬롯머신식 이벤트 연출로 기대감.
- 난이도를 규칙으로 나눔(리롤 수, 레이팅 숨김). 숫자를 가리는 하드 모드는 취향 싸움을 부추김.
- 데일리가 뉴스·생일 같은 시의성과 필수/보너스 조건이라, 매일 같은 게임인데도 풀이가 달라진다. 완성 확률 퍼센트가 실시간으로 내려가는 피드백이 명확.
- 팀 종합 아래 공/중/수/GK 막대로 약점이 한눈에 보이고, 1월 이적이 "가장 약한 자리"를 자동 보강해서 판단 부담을 줄임.
- 리더보드에 "검증됨(서버 확인)" 표시, 동점은 득실차로 구분, 친구 탭 별도. 어떤 팀 구성이었는지(포메이션·종합·레이팅 방식)를 한 줄로 같이 보여줌.
- 시간 건너뛰기: 시즌 중 1월까지, 유럽 리그 페이즈 끝까지 스킵 버튼, 속도 토글.

## 아쉬운 점

- 광고가 많다: 드래프트 화면 상단 영상 광고(소리 음소거 아이콘 있음)와 하단 배너, 앱 설치 배너가 피치를 가려 모바일에서 어수선하다. 광고 때문에 첫 화면이 아래로 밀리고 스크롤 위치가 엉킴(세팅 → 드래프트 전환 시 페이지 맨 아래에 도착해 푸터가 먼저 보였음).
- 스크롤이 길다. 드래프트 한 화면이 약 2,400px: 피치(위) - 종합 막대 - 스핀 영역(맨 아래)이라 스핀·선수 목록까지 스크롤을 많이 해야 하고, 스핀 버튼 높이가 약 40px로 44px 미만. 결과 화면은 약 5,300px.
- 시즌 진행 로그가 피치와 막대 아래 한참 아래에 쌓여서, 진행을 보려면 계속 스크롤해야 함.
- 설정이 너무 많고 기억돼서(이전 판 하드 숨김 설정이 다음 판에도 남음) 의도치 않은 설정으로 시작될 수 있다.
- 하드 모드에선 선택지가 전부 가려지고 순서도 랜덤이라 운이 지나치게 큼. 무작위 첫 선수를 찍어도 구분이 안 됨.
- 선수 사진·엠블럼이 없고 이니셜 원형 아바타뿐. 법적으로는 안전하지만 정서적 보상은 약함 (우리와 같은 처지).
- 로그인을 계속 유도(기록 영구 저장)하고, 지난 데일리는 유료. 로그인 없이는 기록이 기기에만 남음.
- 시즌 결과가 상당히 랜덤이라 같은 팀이 크게 엇나가는 판이 있음. 이변이 재미있지만 "내 팀 탓"이 안 느껴질 수 있음.
- 사전 지식 없으면 클럽·시즌 조합 이름만으로 판단해야 해서 입문 장벽(우리 게임에도 해당).
- 효과음은 확인하지 못했다(조사 환경에서 소리 확인 불가). 시각 효과는 룰렛 회전, 타자기식 결과 줄, 슬롯머신 이벤트, 우승 시 트로피/배너 정도.

## 우리 감독판에 적용할 아이디어 (우선순위)

우리 구조: 역대 레전드 카드로 베스트 11, K리그1 38경기, 겨울 이적, 초청경기. 이미 비슷한 틀이 있으니 "표현과 반복 동기" 위주로 가져온다.

높음 (바로 효과, 작업량 적음)
1. 시즌 시작 전 "사전 예상 카드": 라인업 종합점수 → 예상 순위·승점·우승/ACL권/강등 확률. 시즌 끝에 "예상 대비 초과/각본대로/말아먹음" 한 줄 평가. 이미 확률 계산이 있다면 UI만 추가.
2. 결과 화면의 자동 서사 문단: 득점왕, 겨울 이적 효과(떠난 선수 성적과 새로 온 선수 성적), 최다 점수차 경기, 팀 성향 라벨. 우리 기존 이벤트 문구 풀과 연결하기 쉬움.
3. 시즌 어워드 묶음(득점왕·도움왕·최다 클린시트 GK·MVP·감독). 선수판 awards.js 로직과 공유 가능한지 확인.
4. 한 단계 입력 규칙: "선수 탭 → 포지션 탭" 두 번 안에 끝나게. 스핀·카드 목록이 한 화면에 들어오도록 피치를 접거나 하단 고정 영역으로 구성 (스크롤 최소화, 지침 5번).
5. 라운드 진행 중 건너뛰기 버튼(겨울까지, 시즌 끝까지)과 속도 토글.

중간
6. 겨울 이적을 "되돌리기 없는 한 번의 도박 이벤트"로 통일: 슬롯머신식 연출로 이벤트 하나가 걸리는 방식(예: 최약 포지션 블라인드 영입, 한 클럽 습격, 방출 위기). 결과를 OUT/IN 카드로 보여주고 상승 포인트 표기.
7. 데일리 도전: 날짜마다 필수 조건("특정 선수 포함, 같은 클럽 레전드 2명, 같은 출신 1명")과 보너스. 선택마다 실시간 "완성 확률" 표시. 시즌 서사를 K리그 이슈·기념일(레전드 생일, 개막일)과 묶으면 매일 오는 이유가 됨. 로컬 저장만으로 시작 가능.
8. 난이도를 규칙으로 구분(리롤 수, 레이팅 숨김). 이미 있는 난이도와 겹치는지 확인 후, 특히 "레이팅 숨김 하드"는 선택 옵션으로.
9. 트로피/도전과제: "한 시즌 무패", "서로 다른 출신 10명", "한 팀 5명 이상" 같은 구성 도전과제. 명예의 전당과 연결.
10. 리더보드는 서버 없이도 "내 기기 베스트 기록(최고 승점, 무패 최장)" 로컬 기록판으로 대체. 친구들끼리면 결과 텍스트 복사만으로 충분 (공유 버튼 구현은 지침 7번과 충돌 안 하는 범위로 별도 결정).

낮음
11. 유럽(ACL) 모드: 36팀 리그 페이즈형 연출은 크지만 K리그에선 ACL 시나리오로 확장 가능. 지금은 초청경기 쪽이 우선.
12. 팀 종합 아래 공/중/수/GK 막대 시각화 (우리 라인업 화면에 이미 있다면 생략).
13. 팀 성향 라벨(공격형/중원 장악 등)과 한 줄 평가 문구 20~30종.

## 하지 말 것

- 광고 영상, 하단 배너, 앱 설치 배너로 게임 화면(피치·스핀 버튼)을 가리지 말 것. 모바일 전제인 우리와 정반대.
- 한 화면에 피치·막대·스핀·선수 목록을 세로로 길게 쌓아 놓고 스핀 버튼을 맨 아래에 두지 말 것. 스핀/확정 버튼은 하단 고정, 44px 이상.
- 화면 전환 후 스크롤 위치를 맨 아래에 두지 말 것. 단계 전환 시 항상 맨 위(또는 해당 영역)로.
- 이전 판의 숨김·난이도 설정을 눈에 안 띄게 기억해서 다음 판을 엉뚱하게 시작시키지 말 것. 현재 설정을 시작 전에 한 줄로 요약해서 보여줄 것.
- 설정 옵션을 한 화면에 12개 이상 늘어놓지 말 것. 기본값 한 방 시작 + "고급" 접기.
- 로그인/저장을 계속 압박하지 말 것 (우리 지침 7번: 계정·로그인·결제·공유 버튼 건드리지 않음).
- 레이팅 숨김 하드 모드를 기본으로 두지 말 것. 선택이 의미 없어진다.
- 38-0의 문구·구조·디자인(룰렛 연출, 라벨 이름, 장면 문구)을 그대로 쓰지 말 것. 아이디어(사전 예상 vs 실제, 1월 도박, 데일리 필수 조건)만 우리 용어와 우리 K리그 소재로 다시 만든다.
- 이니셜 아바타만으로 끝내지 말고, 사진 대신 팀 색·유니폼·번호 같은 우리만의 상징으로 감정 보상을 줄 것 (영구결번 유니폼 방향과 일치). 저작권 점검 전 실제 사진·엠블럼은 사용하지 않는다.
