# 2D 경기 보기 계획

목표: 경기마다 FM2012처럼 점(선수)들이 움직이는 2D 화면으로 볼 수 있게 한다.
저작권 때문에 다른 사이트의 코드·화면은 가져오지 않고, 구조만 참고해서 우리 방식으로 따로 만든다.

## 참고한 구조 (남의 사이트 분석 요약)
- 경기를 **먼저 전부 계산한 뒤 재생**한다 (계산은 Web Worker). 결과가 정해져 있어 화면과 기록이 어긋나지 않는다.
- 프레임 데이터는 두 벌: 경기 내내 1.6초 간격(보간) + 결정적 장면만 0.2초 간격.
- 결정적 장면이 오기 전에는 해설을 붙들어 두었다가, 공이 골망에 닿는 프레임에서 함께 푼다 (결과 누설 방지).
- 골은 한 번 더 느린 배속으로 다시 보여준다.

## 우리 구조
1. 시즌 시뮬은 지금 방식 그대로 (포아송 득점, 득점자·도움·카드·부상, 평점).
2. 사용자가 **보기로 한 경기**만 2D 엔진을 돌린다. 이미 정해진 이벤트(득점 분·득점자·도움·카드·교체)는 그대로 지키고, 사이 시간은 역할 기반 움직임으로 채운다.
3. 엔진 출력은 프레임 배열(선수 좌표, 공 좌표, 공 소유자). 재생기는 캔버스에 그린다.

## 단계
1. **1단계**: 포메이션 위치에 점을 놓고, 로그의 이벤트에 맞춰 공과 선수가 해당 구역으로 이동. 배속·일시정지·건너뛰기.
2. **2단계**: 점유율을 반영한 패스 흐름, 수비 라인 이동, 압박, 크로스·슈팅 연출. 능력치는 속도·패스 성공 같은 연출에만 반영.
3. **3단계(선택)**: 선수 역할(윙어·풀백·압박수 등)별 이동 목표, 포메이션 변형(공격 4-3-3 / 수비 5-4-1).

## 주의 (남의 엔진에서 나온 문제들)
- 골키퍼가 공을 쫓다가 뒤돌아서는 오류, 오프사이드를 패스 순간 위치만으로 판정하는 오류, 같은 득점이 두 번 기록되는 오류.
- 우리는 결과를 먼저 정해 두므로 이런 문제를 구조적으로 피한다. 화면이 결과를 바꾸지 않는다.
