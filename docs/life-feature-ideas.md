# 선수판 참고 메모 (다른 게임을 직접 해보고 정리 — 기능 아이디어만, 코드·문구·디자인은 따라 하지 않음)

## 직접 플레이로 확인한 흐름
- 시작: 이름·등번호·국적·체격(키/몸무게)·포지션·주발·주력 능력치 2개·성장 특성 1개 → 스카우트 "후보 3명" 중 1명 선택(총합 같고 분포만 다름) → 잠재력은 숨김(첫 평가는 고3 시즌 후).
- 시즌: 프리시즌(훈련 방향 + 자기 투자 선택) → 전반기 10R → 후반기 10R → 이벤트 확인 → 결과. 구간마다 로딩 팝업(진행 막대와 단계 문구).
- 매 구간: 컨디션·사기·인기 미터, 시즌 누적 기록, 순위표, 컵 대회 결과, 최근 소식(타임라인).
- 하단 탭: 시즌 / 선수 / 커리어 / 트로피 / 홈.

## 우리 게임에 넣을 것 (우리 방식으로)
1. 성장 특성(조기 성장·대기만성·강철 체력·스타성) — 생성 시 선택
2. 스카우트 후보 3명 비교 선택 + 로딩 연출
3. 컨디션·사기·인기 + 자기 투자(약점/강점/메디컬/멘탈) — 엔진 v2에 이미 반영
4. 구간 로딩 팝업 + 구간 요약 + 최근 소식 타임라인
5. 선택지 확률 공개 이벤트(확률 도감)
6. 서버 최초 기록·명예의 전당(우리는 Supabase로 나중에)

## 감독판 이벤트 아이디어 (사용자 요청)
- 중요 경기 전후 인터뷰: 1·2위 결정전, 강등권 직접 대결, 우승 확정 직전
- 선수단 불화: 주전 불만(출전 시간), 베테랑과 신예 갈등, 주장단 영향(리더십 연동)
- 긍정: 선수 깜짝 성장, 팬 응원 이벤트, 스폰서 후원, 선수 미담
- 부정: 부상 악재, 심판 논란, 구단 재정 압박, 선수 이적 요구
- 각 이벤트는 선택지마다 성공 확률 공개, 결과는 사기·팬심·컨디션에 반영

## 추가 관찰 (오프사이드 직접 플레이 + 이번 생은 야구다 홈/나무위키 정리, 기능 아이디어만)
- 스토리 이벤트: "평생의 라이벌 1/3"처럼 여러 구간에 걸쳐 이어지는 이야기(진행 중 스토리 표시, "약 4구간 후").
- 이벤트 선택지는 결과 문구(헤드라인) + 능력치/사기/인기 변화로 마무리.
- 구간 결과 화면: 경기별 결과 칩(승/무/패), 변화 요약, 컵 대회 결과.
- 야구 쪽: 영구결번은 "한 구단 장기 활약 + 우승·수상 기여"가 필요하고 자동이 아님. 커리어 종합점수(Legacy Score)로 1:1 대결.
- 클럽하우스(은퇴 선수 보관 → 12인 팀 → 랭킹), 서버 최초 업적, 시즌 업적(수집형), 명예의 전당. 구단명·로고는 전부 가상.
- 상점은 "슬롯 확장"(선수 슬롯·팀 슬롯)만 판매 → 승패에 영향 없는 편의/보관 확장. 사업자등록·통신판매업 신고 표기.
