# K-레전드 38

시대별 K리그 레전드 팀을 스핀해서 베스트 11을 뽑고, 20팀 38라운드 시즌을 시뮬레이션하는 팬 제작 게임이에요.
서버나 빌드 없이 HTML, CSS, JS 파일만으로 돌아가요.

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   디자인 (색상은 맨 위 :root 변수에서 변경)
js/data.js      팀/선수 데이터 ← 제일 자주 고치게 될 파일
js/game.js      게임 로직 (맨 위 CONFIG에서 난이도 조절)
```

## 내 컴퓨터에서 실행

`index.html`을 더블클릭하면 브라우저에서 바로 열려요.

## 자주 하는 수정

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 선수 추가, 능력치 수정 | `js/data.js` |
| 새 팀(시대) 추가 | `js/data.js`에서 한 줄 복사 후 수정 |
| 38전 전승을 더 어렵게/쉽게 | `js/game.js` 맨 위 `CONFIG.SPREAD`, `GOAL_BASE` |
| 다시 스핀 횟수 | `CONFIG.RESPINS` |
| 포메이션 추가 | `js/game.js`의 `FORMS` (좌표는 경기장 기준 %) |
| 색상 | `css/style.css` 맨 위 `:root` |

선수 한 명 형식은 `["이름", "포지션", 능력치, "보조포지션"]`이에요. 보조포지션은 없으면 생략해도 돼요.

```js
["울산 현대","울산","2022–23",85,[
  ["조현우","GK",86],
  ["이청용","MF",85,"FW"],
  ...
]],
```

수정한 다음에는 브라우저를 새로고침하면 바로 반영돼요. 화면이 하얗게 나오면 대부분 쉼표나 괄호가 빠진 거예요.

## 친구들이랑 하기 (무료 배포)

### 방법 1. Netlify Drop (가장 쉬움, 5분)
1. https://app.netlify.com/drop 에 접속해요.
2. 이 폴더 전체를 화면에 끌어다 놓아요.
3. `xxxx.netlify.app` 주소가 나오면 단톡방에 공유하면 끝이에요.
4. 수정 후에는 사이트 관리 화면의 Deploys에서 폴더를 다시 끌어다 놓으면 돼요. 회원가입을 하면 주소가 유지돼요.

### 방법 2. GitHub Pages (계속 고쳐 나갈 거면 추천)
1. GitHub에 새 저장소를 만들고 이 파일들을 올려요.
2. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 설정해요.
3. `아이디.github.io/저장소이름` 주소로 공개돼요.
4. 파일을 수정해서 올리면 1~2분 뒤 자동으로 반영돼요.

## 주의

- 비공식 팬 게임이에요. 구단 엠블럼이나 공식 이미지는 넣지 마세요. 초상권과 상표권 문제가 생길 수 있어요.
- 능력치는 주관 평가예요. 공개 범위를 넓히거나 수익화하려면 먼저 검토가 필요해요.
- 최고 기록은 각자 브라우저에만 저장돼요. 친구들끼리 순위표를 공유하려면 서버(DB)를 붙여야 해요.
