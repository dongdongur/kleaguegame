# K-레전드 38

시대별 K리그 레전드 카드를 뽑아 베스트 11과 후보 5명, 감독을 꾸리고, 2026 K리그1에 합류해서
리그(38라운드) · FA컵 · ACL에 도전하는 팬 제작 축구 게임이에요. 시즌을 이어가며 겨울 이적시장에서
선수단을 손볼 수 있고, 친구 팀과 맞대결도 할 수 있어요.

## 폴더 구조

```
index.html          화면 뼈대
css/style.css       FIFA 스타일 디자인 (색은 맨 위 :root 변수)
js/data.js          레전드 팀·선수 데이터, 감독 데이터   ← 제일 자주 고치는 파일
js/data2026.js      2026 K리그1 상대팀 선수단
js/data_cups.js     FA컵·ACL 상대팀, 더비 목록
js/config.js        Supabase 연결 정보 (공개용 anon 키)
js/core.js          밸런스 설정(CONFIG), 포메이션, 능력치 계산
js/season.js        시즌 엔진 (리그·FA컵·ACL, 체력·카드·부상, 시상)
js/ach.js           업적·배지
js/game.js          화면과 진행 (드래프트, 겨울 이적시장, 결과)
js/share.js         친구 기록 DB (Supabase)
js/duel.js          친구 팀 맞대결
supabase/schema.sql DB 설정 SQL
```

## 내 컴퓨터에서 실행

`index.html`을 더블클릭하면 돼요. (친구 기록 기능은 인터넷 연결이 필요해요.)

## 게임 규칙 요약

- **드래프트**: 연도+팀(그 팀 선수 전원 공개) 또는 연도+포지션(그 해 그 포지션 선수 5명) 중 선택. 선발 11명 → 감독 → 후보 5명(연달아 뽑기).
- **포지션**: 선수는 그 시즌에 실제로 뛴 세부 포지션 자리에만 설 수 있어요.
- **케미**: 같은 팀·시즌 출신, 같은 시기 국가대표끼리 짝지을수록 공격·수비 보너스.
- **시즌**: 리그 12팀 38라운드(33 + 파이널 5), FA컵 4라운드, 전 시즌 3위 이내이거나 FA컵 우승이면 ACL(조별 6경기 + 토너먼트).
- **체력·카드·부상**: 경기마다 체력이 닳고 후보가 로테이션해요. 퇴장은 다음 경기 결장, 경고 5장이면 1경기 결장, 부상은 몇 경기씩 결장.
- **겨울 이적시장**: 시즌 사이에 능력치가 변하고(성장·하락), 영입 3회와 감독 교체 1회.
- **난이도**: 쉬움은 상대의 2026년 능력치, 어려움은 상대 선수 전원이 전성기 능력치.
- **승패 계산식**은 `js/core.js` 맨 위 `CONFIG`와 `js/season.js`에 있어요. 득점 기대값 = `GOAL_BASE × exp((공격 − 상대 수비) / SPREAD)`, 득점은 푸아송 분포.

## 자주 하는 수정

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 선수 추가, 능력치·세부 포지션 수정 | `js/data.js` |
| 감독 추가·수정 | `js/data.js` 맨 아래 `KL_MANAGERS` |
| 2026 상대팀 선수·능력치 수정 | `js/data2026.js` |
| 난이도, 체력, 카드, 부상 확률 | `js/core.js` 맨 위 `CONFIG` |
| 대회 일정(몇 라운드 뒤에 열리는지) | `CONFIG`의 `FA_AFTER`, `ACL_*_AFTER` |
| 업적 추가 | `js/ach.js` |
| 색상 | `css/style.css` 맨 위 `:root` |

선수 한 명 형식: `["이름", "큰 분류", 능력치, "보조 큰 분류", "세부 포지션"]`
세부 포지션은 `"LW/ST"`처럼 그 시즌에 뛴 자리를 적어요 (GK, LB, CB, RB, DM, CM, AM, LM, RM, LW, RW, ST).
수정한 다음에는 새로고침하면 바로 반영돼요. 화면이 하얗게 나오면 대부분 쉼표나 괄호가 빠진 거예요.

## 배포 (GitHub → Cloudflare)

1. 변경한 파일을 GitHub 저장소에 push해요.
2. Cloudflare Pages(또는 Workers)가 자동으로 새로 배포해요. 1~2분 뒤 같은 주소에 반영돼요.

## 친구 기록 DB (Supabase) 설정

친구들과 기록·맞대결을 공유하려면 한 번만 설정하면 돼요.

1. https://supabase.com 에서 프로젝트를 만들고, **Project Settings → API**에서 `Project URL`과 `anon public` 키를 `js/config.js`에 넣어요.
   (anon 키는 공개해도 되는 키예요. `service_role` 키는 절대 넣지 마세요.)
2. 대시보드 왼쪽 메뉴 **SQL Editor → New query**에 `supabase/schema.sql` 내용을 통째로 붙여넣고 **Run**을 눌러요.
   새 기능(난이도, 맞대결)을 추가한 뒤에는 이 파일을 다시 Run하면 돼요. 여러 번 실행해도 안전해요.

## 주의

- 비공식 팬 게임이에요. 구단 엠블럼이나 공식 이미지는 넣지 마세요. 초상권과 상표권 문제가 생길 수 있어요.
- 능력치와 2026 선수단은 주관 평가·위키 기반 초안이라 실제와 다를 수 있어요. 공개 범위를 넓히거나 수익화하려면 먼저 검토가 필요해요.
- 업적과 최고 기록은 각자 브라우저에 저장돼요. 친구들과 공유되는 건 "친구들 기록"에 올린 시즌 결과뿐이에요.
